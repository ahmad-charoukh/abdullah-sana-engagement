# عبدالله وسنا — دعوة حفل خطبة

موقع فعلي للموبايل، مبني على Next.js App Router وTypeScript. يحتوي دعوة تفاعلية ولوحة تحكم محمية وتخزين SQLite محلي أو D1 وR2 على Cloudflare. للنشر على Cloudflare اتبع [CLOUDFLARE.md](CLOUDFLARE.md). الخطوط مستضافة محليًا تحت ترخيص SIL OFL؛ تراخيصها في `licenses/`.

## التشغيل المحلي

يتطلب Node.js **22.13 أو أحدث** (اختُبر على Node 24).

```bash
npm ci
npm run dev
```

الدعوة: http://localhost:3000
لوحة التحكم: http://localhost:3000/admin

الدخول المحلي الافتراضي:
- اسم المستخدم: `admin`
- كلمة المرور: `ChangeMe-Sana-2026!`

لتخصيص بيانات الدخول، انسخ `.env.example` إلى `.env.local` وعدّل القيم، ثم أعد تشغيل الخادم.

## نسخة الإنتاج

اضبط `ADMIN_USERNAME` و`ADMIN_PASSWORD` في `.env.local` أو بيئة الخادم. دخول لوحة التحكم في الإنتاج معطّل دون `ADMIN_PASSWORD`.

```bash
npm run build
npm start
```

استضف التطبيق على خادم Node.js بقرص دائم وHTTPS (خادم واحد لتخزين SQLite المحلي). `DATA_DIR` اختياري، وهو مسار قاعدة البيانات والملفات المرفوعة؛ الافتراضي `./data`. `APP_URL` اختياري، مثل `https://invitation.example` للتحقق من المصدر. احتفظ بنسخ احتياطية من مجلد البيانات، ولا تضعه ضمن ملفات الموقع العامة. لا تستخدم التخزين المحلي على منصات ذات قرص مؤقت. تتضمن هذه النسخة محوّلي D1 وR2 جاهزين عند البناء لـ Cloudflare، مع عزل المكتبات المحلية عن حزمة Workers.

## الوظائف

- فتح ظرف ثلاثي الأبعاد، رفع البطاقة، وفتح طرفي بطاقة الأسماء مرة واحدة.
- ورود فوتوغرافية مستقلة عن صورة المرجع، خلفية ورقية وحواف ذهبية، RTL وخطوط محلية.
- تغيير الأغنية من `/admin` ← الموسيقى ← «تغيير الأغنية — رفع MP3». يتم الاستبدال والحفظ تلقائيًا بعد الرفع. مقطع موسيقي أصلي هادئ مرفق، تشغيل بعد التفاعل، إيقاف، تحكم بالصوت وتكرار اختياري. يمكن استبداله بملف MP3 من لوحة التحكم.
- موعد الرجال 4:00 مساءً وموعد النساء 6:00 مساءً، ويمكن تعديل الوقتين والعنوانين من لوحة التحكم. عد تنازلي فعلي مع المنطقة الزمنية. اليوم يحسب تلقائيًا أو يخصص من لوحة التحكم. 9 أكتوبر 2026 يوافق الجمعة.
- المكان عام دون مدينة أو قاعة محددة، مع رابط خرائط اختياري.
- RSVP فعلي، قبول واعتذار، منع تكرار سريع، وتحديث الرد بدلاً من مضاعفته للاسم نفسه خلال يوم.
- تهانٍ مع موافقة/رفض/حذف؛ لا يُنشر إلا المقبول عند تفعيل الموافقة.
- قسم الصور مخفي افتراضيًا بناءً على الطلب الأخير، ويمكن تفعيله من لوحة التحكم. صور قابلة للرفع والحذف والترتيب بالسحب أو أزرار لوحة المفاتيح، وتحديد غلاف ووصف بديل. المعرض يبدأ فارغًا إلى أن ترفع صورك، مع أسهم وسحب وثمبنيل.
- تنزيل تقويم ICS ومشاركة الدعوة ونسخ رابطها.
- تعديل جميع النصوص الرئيسية والأسماء والألوان والتاريخ والموسيقى من لوحة التحكم.

## التخزين والحماية

الجداول: `settings`, `event_details`, `rsvps`, `wishes`, `gallery`, `media`, `sessions`, `rate_limits`.
الجلسات HttpOnly / SameSite Strict / Secure في الإنتاج، مدة 12 ساعة. تُخزن بصمتها فقط في قاعدة البيانات، وتُفحص بصمتا SHA-256 لكلمة المرور المدخلة والسر المضبوط بمقارنة ثابتة الوقت. كلمة مرور الإدارة محفوظة كسر بيئي وليست سجلًا في قاعدة البيانات. طلبات التعديل تتحقق من المصدر، مع تحديد معدل المحاولات. كل النصوص تعرضها React كنص، دون HTML قابل للتنفيذ.

الصور المقبولة: JPEG / PNG / WebP حتى 10MB؛ تُحجَّم من لوحة التحكم إلى حد أقصى 1600px وتُحوَّل إلى WebP قبل رفعها. يضيف التخزين المحلي فحصًا وتحويلًا عبر sharp، ويتحقق محوّل R2 من توقيع نوع الملف. الموسيقى MP3 حتى 15MB، مع دعم طلبات Range للمشغّل. التخزين منفصل عن العرض، ولا تتضمن قاعدة البيانات صورًا أو موسيقى base64.

## الاختبارات

```bash
npm run typecheck
npm run build
npm test
npx playwright install chromium
npm run test:ui
```

اختبارات API والمتصفح تشغّل خادمًا داخل العملية وتستخدم قاعدة بيانات مؤقتة منفصلة؛ لا تغيّر بيانات الدعوة. `CHROMIUM_EXECUTABLE` اختياري لاستخدام متصفح موجود، و`SCREENSHOT_DIR` اختياري لحفظ لقطات الفحص.

التوافق الميكانيكي اختُبر على Chromium بعروض 375 / 390 / 393 / 430 / 768 / 1440px، إضافة إلى reduced motion. التشغيل على iOS Safari وAndroid يحتاج تحققًا على أجهزة فعلية قبل النشر العام؛ لم تُستخدم أجهزة فعلية في اختبار هذا الـWorkspace.

## الأصول

`public/assets/floral-corner.webp`: أصل فوتوغرافي مولّد، مخصص لهذا المشروع، دون أي نص أو تصميم واجهة. صورة المرجع لم تُستخدم خلفية أو عنصرًا داخل الموقع.
`public/assets/quiet-celebration.mp3`: مقطع آلي أصلي قصير صُنع لهذا المشروع، دون عينات أو كلمات من تسجيلات خارجية.

## تحديث الملفات دون فقد البيانات

استبدل ملفات المصدر من النسخة الجديدة مع الاحتفاظ بمجلد `data` وملف `.env.local` الحاليين، ثم أعد تشغيل الخادم. إصلاح فحص المصدر يسمح بالنماذج عند استخدام localhost أو عنوان الشبكة حتى إذا كان عنوان الخادم الداخلي مختلفًا.
